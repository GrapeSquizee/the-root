# THE ROOT 첫 분류 UI·UX 기준

## 화면의 역할

이 게임에서 선택은 지식 퀴즈의 정답 버튼이 아니라 세계의 분류 기록이다. 제목 화면은 세계수와 어두운 질서의 공간을 보여주고, 플레이 화면에서는 개체를 중심에 놓는다. 분류 경로는 왼쪽, 관찰 기록은 오른쪽에 두어 현재 판단의 근거와 결과를 동시에 볼 수 있다.

`docs/ref_img`의 8개 이미지에서 세계수, 부유섬, 어두운 자연색, 얇은 금빛 선, 중앙 개체 카드, 좌우 갈래 구도를 참고했다. 참고 이미지에 들어 있던 가상 글자·버튼·수치·장비 UI는 게임 데이터와 맞지 않아 사용하지 않았다. `game/assets`의 배경·개체 그림 4개는 그 분위기를 바탕으로 생성한 별도 게임 자산이다.

## 플레이 흐름

1. 제목: “분류를 시작한다”를 눌러 첫 개체를 연다.
2. 판단: 개체 그림과 이름, 현재 깊이, 두 갈래와 일상어 설명을 함께 본다. 용어 설명은 무료다.
3. 관찰: 필요할 때 한 번 사용해 개체 단서를 본다. 카드 최종 점수 −30%를 선택 전에 표시한다.
4. 선택: 왼쪽/오른쪽 버튼 또는 방향키로 분류한다. 맞힌 경로는 왼쪽에 누적된다.
5. 카드 종료: 완주·확정·오답·건너뛰기의 판정 기록을 읽고 다음 개체로 진행한다. 오답은 선택한 갈래와 정답 갈래의 뜻을 표시한다.
6. 결과: 3개체의 결과와 총 점수·CHAOS를 확인하고 다시 시도할 수 있다.

한 판의 점수·CHAOS는 실제 데이터와 로직에서 가져온다. 아직 규칙이 정해지지 않은 ORDER 비율, 가짜 Cycle 시간, 장비 슬롯은 화면에 그리지 않는다.

## 시각 규칙

- 개체 그림과 선택지가 시선의 중심이다. 양옆의 분류 경로·관찰 기록은 보조 정보다.
- 황금색은 세계의 분류선과 중요한 상태 표시에 쓴다. 활성화되지 않은 행동은 흐리게 표시한다.
- 배경은 글자 없는 풍경 그림이다. 버튼·제목·판정 문구는 Godot UI로 따로 그려 실제로 동작한다.
- 제목·카드·판정·결과의 분위기를 이어가되, 오답과 건너뛰기는 다른 결과로 명확히 말한다.

## 다음 검증

- 실제 플레이어가 용어 설명만으로 선택을 이해하는지 관찰한다.
- 판정 기록이 너무 자주 흐름을 끊는지 측정한다.
- 1280×720 외 해상도와 한국어 글꼴 대체 환경을 확인한다.
- 정식 20개체 빌드에서 개체별 그림 제작 범위와 이미지 품질 기준을 정한다.
