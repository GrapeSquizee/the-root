# 낮과 밤 프로토타입

[컨셉 재설계](../../docs/13_THE_ROOT_컨셉_재설계_낮_분류_밤_방어.md)의 낮 분류 → 저녁 준비 → 밤 방어 → 새벽 정산 루프를 도형만으로 시험하는 빌드다. 기존 첫 분류 빌드(`main.tscn`)와는 따로 돈다.

## 실행

Godot 4.7.2에서 `game/project.godot`을 열고 `res://daynight/day_night.tscn`을 연 뒤 **F6**(현재 씬 실행)을 누른다.

## 조작

| 단계 | 조작 |
|---|---|
| 낮 | ←/→ 또는 A/D: 분류, ↓ 또는 S: 여기서 멈추기 |
| 저녁 | 선 클릭: 노란 실 걸기/거두기(실타래 1), F: 고정, Enter: 밤 시작 |
| 밤 | 집 클릭: 잇기(주변 해체자를 쫓아낸다, 실타래 1), Space 또는 우클릭 누르고 있기: 집중(느린 시간), F: 고정 |
| 새벽 | Enter: 다음 날 |

## 들어간 규칙

- 3일. 하루에 카드 6장. 카드마다 걸린 집이 있다.
- 첫날 제한 시간 `4.0`, 둘째 날부터 `2.0`(첫 카드에 `튜토리얼 종료.` 표시).
- 정답 한 단계마다 실타래 +1, 남은 시간의 1/4만큼 집중.
- 오답: 첫 단계에서 틀리면 가는 붉은 줄(1), 더 내려가다 틀리면 굵은 줄(2). 붉은 줄은 하루에 한 칸씩 옅어진다.
- 시간 초과: 오답으로 치지 않는다. 실타래도 붉은 줄도 생기지 않는다.
- 저녁에 해체자 경로를 점선으로 미리 보여 준다. 해체자는 붉은 줄이 걸린 집을 거쳐 기록 천으로 가며, 우물로는 들어가지 않는다.
- 해체자가 이름이 남은 집에 닿으면 멈춰서 이름을 끊는다. 붉은 줄이 굵을수록 빨리 끊긴다.
- 기록 천에 닿은 해체자는 천의 선을 하나 끊는다(12개). 0이 되면 끝난다.
- 고정: 그 밤 동안 집과 천이 끊기지 않는다. 대신 새벽에 새 잎이 펴지지 않고 안정화율이 오르지 않는다. 서린의 손 +1(3이 한도), 2일 재사용 간격.
- 붉은 줄이 4칸 이상이면 그날 밤 웨이브가 하나 늘어난다.

## 아직 없는 것

재출제(틀린 대상을 다시 맞혀 붉은 줄을 지우기), 소리, 인물 반응, 카드의 깊이별 실타래 강도, 해체자 유형, 밸런스.
