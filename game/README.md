# THE ROOT — 첫 분류 빌드

Godot 4.7.2에서 `game/project.godot`을 열고 **F6 또는 F5**로 실행한다. 데이터는 사용자 기획서의 Excel·JSON에서 `tools/export_prototype.py`로 추출했다.

이전에 띄운 게임 창은 코드 변경 후에도 옛 화면을 보여줄 수 있다. 창을 닫고 Godot에서 다시 실행한다. 현재 화면 상단의 버전 표시는 `FIELD TEST 02`다.

현재 화면의 구성과 판단 흐름은 `UI_UX.md`에 정리했다.

고양이 → 물 → 오리너구리 순서로 플레이한다. 좌우 버튼 또는 방향키로 분류를 선택한다. 관찰은 카드당 1회, 최종 점수 -30%다. 한 단계라도 맞힌 뒤에는 **여기서 확정**할 수 있고, 건너뛰기는 점수 0·CHAOS +2다. 오답은 현재 카드 점수 절반·CHAOS +5다. 완주할 때 3초/5초 빠른 보너스가 적용된다.

선택지 아래에는 학술 분류명의 뜻을 일상어로 설명한다. 이 설명은 점수 비용 없이 항상 보인다. **관찰**은 개체에 대한 추가 단서를 얻는 행동이며, 분류 용어를 이해하기 위한 비용이 아니다. 현재 설명 문구는 3장 프로토타입용 초안이다.

`docs/ref_img`의 세계수·금빛 분류선·중앙 개체 카드 구도를 바탕으로 제목 화면과 플레이 화면을 만들었다. 배경과 고양이·물·오리너구리 그림은 참고 이미지를 바탕으로 글자 없는 게임용 자산으로 별도 생성했다. 게임 화면은 분류 경로(왼쪽), 개체와 선택(중앙), 관찰 기록(오른쪽)으로 구성된다. 카드가 끝나면 판정 기록을 확인한 뒤 다음 개체로 진행한다.

플레이가 끝나면 결과 화면에 로그 경로가 표시된다. `user://first_classification_log.json`에 선택과 카드 결과가 저장된다. 다시 도전하기는 새 게임을 시작한다.

이 빌드는 첫 마일스톤의 분류 조작·점수·로그를 검증한다. 5분 Cycle, 상점, 장비, 저장 복구, Overflow는 이후 단계다. `start_depth`를 건너뛴 상위 분류 점수는 지급하지 않는다. OBSERVE 패널티는 LOCK/오답에도 적용한다. 이 두 처리 방식은 분석 보고서의 미확정 규칙을 프로토타입에서 일관되게 시험하기 위한 임시 결정이다.

원본 데이터를 수정한 뒤 재생성하려면 번들 Python으로 `python game/tools/export_prototype.py`를 실행한다. Excel은 표시명, JSON은 문제/정답의 기준이다.
