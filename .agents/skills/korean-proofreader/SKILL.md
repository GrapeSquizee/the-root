# 한국어 문법검사

이 스킬은 프로젝트에 속한다. 아래 경로는 프로젝트 루트를 기준으로 한다.

## 작성자와 검사자의 역할

작성자는 저장한 문서를 직접 재독한 뒤 `korean_proofreader` 한 명에게 검사를 맡긴다. 등록된 사용자 정의 에이전트를 선택할 수 없는 도구에서는 일반 하위 에이전트 한 명에게 `.codex/agents/korean-proofreader.toml`과 이 스킬을 읽게 한다. 여러 파일은 한 작업으로 묶고, 재검사는 같은 에이전트에게 맡긴다.

검사자로 실행 중이라면 다른 에이전트를 호출하지 않는다. 파일을 쓰지 않고 지적만 보고한다. 검사 후 원고를 고치는 책임은 작성자에게 있다. 검사 도구가 없을 때는 직접 점검하되 독립 검사를 했다고 주장하지 않는다.

## 검사 입력과 범위

- 대상 파일의 정확한 경로, 변경 구간, 사용자의 요청과 유지할 표현을 전달받는다. 이전 요약만으로 검사하지 않고 저장된 최신 파일을 연다.
- `docs/AGENTS.md`와 [검사 기준](references/korean-rules.md)을 읽는다. 소설이면 `docs/10_THE_ROOT_인물_목소리_바이블.md`를 읽는다. 외형이나 설정을 판단할 때만 해당 시각 바이블·구성안을 추가로 확인한다.
- 새 화와 전면 개작은 전체를 읽는다. 부분 수정은 해당 장면 전체와 앞뒤 연결 문단을 읽는다. 규칙·설정 문서는 전체를 읽고 지시 사이의 충돌도 확인한다. 다른 문서는 수정 구간과 그 의미에 필요한 앞뒤 문맥을 읽는다.

## 세 번의 점검

1. **표기:** 오탈자, 활용, 조사·의존 명사·보조 용언의 띄어쓰기, 따옴표와 문장 부호를 확인한다. 원칙과 허용 표기를 구별한다. 코드, URL, 경로, 식별자와 의도적인 화면 표시는 일반 문장 규칙으로 바꾸지 않는다.
2. **문장:** 주어·목적어·서술어와 수식어의 호응, 조사, 시제, 필요한 성분의 누락을 확인한다. 누가 무엇을 하는지, 감사·사과·부탁의 대상과 이유가 맞는지 판단한다. 문법상 성립하는 문맥 문제를 맞춤법 오류라고 부르지 않는다.
3. **순차 독해:** 새 대상의 선행 설명, 대화의 계기, 장면 전환, 지시어의 대상과 시점 인물의 지식을 확인한다. 긴 동작 나열과 지나치게 끊긴 문장도 문맥 속에서 판단한다. 줄거리를 새로 쓰거나 일부러 남긴 미스터리를 설명해 버리지 않는다.

은솔의 `...`, 마루의 `~`, 남자의 `*딸꾹*`, 연우의 존댓말과 서린의 차가운 말투를 보존한다. 대사의 생략은 문맥으로 뜻이 통하면 유지한다. 정적인 장면의 비유와 급박한 장면의 짧은 호흡을 일괄 교정하지 않는다.

불확실한 표기나 용법은 기준 문서에 연결된 국립국어원 규범·사전·온라인가나다에서 확인한다. 질문자의 추측과 공식 답변을 구별하며, 인터넷에 원고 전체를 전송하거나 외부 검사 서비스에 업로드하지 않는다. 검색에는 필요한 단어와 짧은 문형만 사용한다.

## 보고와 반영

먼저 실제 읽은 파일과 범위를 밝힌다. 지적마다 `파일:행 / 유형 / 원문 / 최소 수정안 / 이유`를 적는다. 유형은 다음과 같다.

- **확정 오류:** 규범이나 문장 구조에 명확히 어긋남. 규범 문제는 조항이나 확인한 공식 근거를 적는다.
- **문맥상 어색함:** 표기 자체는 가능하지만 이 장면에서 대상·뜻·대화가 어긋남. 어떤 앞뒤 문맥 때문인지 설명한다.
- **확인 필요:** 문맥이나 설정이 부족하여 단정할 수 없음. 임의로 설정을 채우지 않는다.

허용 표기와 취향 차이만 남으면 필수 수정으로 보고하지 않는다. 문제를 발견하지 못했으면 그렇게 보고하고, 정확성을 보장한다고 주장하지 않는다.

작성자는 지적을 문맥과 대조해 필요한 최소 수정만 반영한다. 수정한 문단과 앞뒤를 다시 읽는다. 의미·연결을 바꾸었거나 판단이 남으면 같은 검사 에이전트에게 변경된 결과를 재검토시킨다. 최종 답변에는 실제 수정과 검사 범위만 간단히 알린다.
