# 한국어 교정 기준과 공식 근거

확인일: 2026-10-02. 공식 자료에서 검사에 필요한 기준만 요약했다. 아래 예문은 검사 방법을 설명하기 위해 만든 예문이다. 규범은 표기를 판단하는 기준이고, 소설의 개별 문장과 대화가 자연스러운지는 문맥으로 판단한다.

## 맞춤법·띄어쓰기

출처: 국립국어원 [한국어 어문 규범 — 한글 맞춤법](https://www.korean.go.kr/kornorms/m/m_regltn.do).

- **제41항, 조사:** 앞말에 붙인다. `연우 에게`는 `연우에게`로 고친다. 조사인지 독립된 명사인지 문장 속 기능을 먼저 판단한다.
- **제42항, 의존 명사:** 앞말과 띄어 쓴다. `볼 수 있다`, `떠난 지 오래다`처럼 쓴다. 모양이 같은 조사·어미까지 띄지 않는다. `떠난 지`와 `떠났는지`는 기능이 다르다.
- **제43항, 단위 명사:** 띄어쓰기가 원칙이지만 숫자 등과 붙여 쓰는 허용 사례가 있다. `한 개`와 `3개`를 모두 잘못이라고 처리하지 않는다.
- **제47항, 보조 용언:** 띄어쓰기가 원칙이며 붙임이 허용되는 구성도 있다. `읽어 보다`와 허용 표기 `읽어보다`를 모두 인정한다. 모든 보조 용언을 무조건 붙이거나 떼지 않는다. 앞말에 조사나 합성·파생 구조가 있으면 조항의 해설과 예외를 확인한다.

보조 용언의 세부 확인: 국립국어원 [온라인가나다 — 보조 용언 띄어쓰기, 2026-05-11 답변](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&pageIndex=1&qna_seq=331002). 합성·파생 용언의 활용형 길이에 관한 해설을 확인할 수 있다. 질문에 적힌 예시와 해석이 모두 공식 결론인 것은 아니다.

단어의 뜻·품사·활용형은 [표준국어대사전](https://stdict.korean.go.kr/main/main.do)으로 확인한다. 필요한 조사와 실제 문형은 [한국어기초사전](https://krdict.korean.go.kr/kor/mainAction)의 용례도 참고한다. `되/돼` 같은 활용 문제나 `-던/-든`, `로서/로써` 같은 의미 차이를 발음이나 단순 치환만으로 판정하지 말고 문장 기능을 확인한다.

## 문장의 호응과 의미

출처: 국립국어원 [쉬운 공공언어 쓰기 길잡이](https://m.korean.go.kr/front/etcData/etcDataView.do?etc_seq=399), 본문 17~20쪽의 문장 구성·호응·생략·배열 점검. 공공문서의 문체를 소설에 강제하지 않고 문장의 명료성을 판단하는 기준만 적용한다.

- 주어와 서술어, 목적어와 동사, 수식어와 수식 대상이 맞는지 확인한다. 서로 다른 인물의 행동이 한 주어 아래 섞이지 않았는지 살핀다.
- 생략은 문맥에서 복원할 수 있는지가 기준이다. 대상이 분명한 대사나 혼잣말을 모두 완전한 문장으로 늘리지 않는다.
- 시제와 사건 순서가 맞는지, 긴 수식과 여러 절이 핵심 행동을 가리는지 확인한다. 길다는 이유만으로 문장을 자르지 않는다.
- 감사·사과·부탁은 말하는 사람, 상대, 계기를 확인한다. 예컨대 도움을 준 연우에게 감사하는 장면의 `물이 다시 찬 건 고마워`는 `우물을 손봐 줘서 고마워`로 바꾸면 감사의 이유가 분명해진다. 이것은 해당 장면의 문맥 교정이며, 비슷한 형태의 문장 전부가 문법 오류라는 뜻은 아니다.

## THE ROOT에서 보존할 표현

세부 기준과 최신 설정의 원본은 `docs/AGENTS.md` 및 `docs/10_THE_ROOT_인물_목소리_바이블.md`다. 충돌하면 사용자의 최신 요청과 직접 수정한 원고를 우선한다.

- 인물별 말버릇, 존대 여부와 의도적인 말끝 흐리기는 유지한다. `...`, `...?`, `~`, `~?`, `*딸꾹*`을 일괄적으로 표준 문장 부호로 바꾸지 않는다.
- 스크린의 `분류:`, `최종 분류:`, `4.0`은 설정에 속한다. 현실의 시간 단위를 임의로 덧붙이지 않는다.
- 창작 인명·생물명은 사전에 없다는 이유로 오탈자가 되지 않는다. 이름이 소개되기 전의 호칭과 소개된 뒤의 호칭은 문맥으로 구별한다.
- 비유, 의인화, 신비한 현상 자체를 오류로 처리하지 않는다. 실제 행동과 대상이 불분명해지는 경우에만 문맥 교정을 제안한다.

## 검사에서 구별해야 할 예

| 예문 | 판단 |
| --- | --- |
| `저는 할수 있어요.` | `할 수`로 교정: 의존 명사 띄어쓰기. |
| `제가 해도 되요?` | `돼요`로 교정: `되어요`의 준말. |
| `연우에게 물을 건넸다.` | 유지: 앞뒤에서 행위자가 분명하면 주어 생략 가능. |
| `우비는 소매를 접어 입었다.` | 착용자가 불분명하면 문맥 확인 후 `마루는 우비 소매를 접어 입었다.` 등으로 교정. |
| `물이 모자라서...` | 유지: 은솔의 말끝 흐리기이며 문맥으로 이유가 통하면 오류가 아님. |
| `한 번 읽어보다.` | 보조 용언 붙임 허용. 취향만으로 오류 처리하지 않음. |
| `그 집에 들어가있다.` | `들어가 있다`로 교정: 합성 용언 뒤의 보조 용언. |
| `왜 가면 안 되는지 몰랐다.` | 앞에 이동을 막는 상황이 설명됐다면 유지. |

예문은 기계적으로 치환하는 목록이 아니다. 대상 문장을 앞뒤와 함께 읽고 적용한다.
