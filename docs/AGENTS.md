# 문서 작업 규칙

이 폴더에서 문서를 새로 쓰거나 고치기 전에 해당 문서의 목적과 연결된 기존 문서를 확인한다. 소설 작업에는 반드시 [인물·목소리 바이블](10_THE_ROOT_인물_목소리_바이블.md)의 문장, 선행 설명, 장면 전환, 시점, 관계, 퇴고 기준을 읽고 적용한다. 외형을 묘사할 때는 [인물 시각 바이블](12_THE_ROOT_인물_시각_바이블.md)의 관련 인물과 이미지를 확인한다. 인물이나 세계 설정을 바꿀 때는 구성안과 모순이 없는지 확인한다. [10화 구성안](07_THE_ROOT_장편_10화_구성안.md)은 전체의 큰 사건을, [100화 구성안](09_THE_ROOT_100화_시리즈_구성안.md)은 실제 연재 순서를 정한다.

사용자의 최신 첨삭과 직접 수정한 원고를 우선한다. 분량이나 말버릇에 관한 개별 요청을 모든 장면에 기계적으로 확대하지 않는다. 새 요청이 기존 기준을 바꾸면 관련 규칙과 설정도 함께 정리한다.

## 집필·수정 후 반드시 다시 읽기

1. 먼저 수정할 장면과 앞뒤 연결을 읽고, 사용자가 지적한 문제를 확인한다. 이어지는 화를 쓸 때는 직전 화의 현재 원고를 읽어 사용자의 수정과 남아 있는 감정·물건·약속을 반영한다.
2. 원고를 쓰거나 고친다. 분량을 늘릴 때는 인물의 관찰, 판단, 기억, 관계 변화에 필요한 내용을 보탠다. 불필요한 이동과 동작을 나열해 길이를 채우지 않는다.
3. 저장한 원고를 다시 열어 첫 문장부터 순서대로 읽는다. 새 화나 전면 개작은 해당 화 전체를, 부분 수정은 해당 장면 전체와 앞뒤 연결 문단을 읽는다. 수정한 문장만 확인하거나 검색 결과만 보고 검토를 끝내지 않는다.
4. 독자가 그때까지 읽은 내용만으로 대상과 위치, 대화의 계기, 행동의 이유를 이해할 수 있는지 확인한다. 모든 문장의 주어·목적어·서술어 호응과 시제, 문장 성분의 누락, 중복 표현을 점검한다. 맞춤법이 맞더라도 의미나 구어 표현이 어색하면 고친다. 대화는 인물의 나이·관계·상황에 맞는 구어체로 쓰고, 대사만 따로 떼어 말하듯이 읽으며 어색한 문어체와 해설문 같은 설명을 다듬는다. 문장 호흡, 화자 구분, 인물의 지식 범위, 관계의 거리, 사건 뒤의 반응도 함께 점검한다.
5. 다시 읽다가 부자연스러운 부분을 발견하면 전달 전에 한 번 더 고친다. 재수정한 문단은 앞뒤 문단과 이어 읽고, 연결이나 설정을 바꿨으면 해당 장면도 다시 읽는다. 퇴고 과정에서 불필요하게 원고 전체를 재작성하지 않는다.

규칙이나 설정 문서 자체를 고칠 때도 수정 후 전체를 다시 읽고, 서로 충돌하거나 오해할 만한 지시를 정리한다.

## 한국어 문법검사 에이전트

작성자의 재독을 마친 뒤에는 [한국어 문법검사 스킬](../.agents/skills/korean-proofreader/SKILL.md)을 적용해 검사 에이전트 `korean_proofreader` 한 명에게 저장된 최신 문서를 독립 검토시킨다. 여러 파일을 고치는 한 작업은 묶어서 검사하고, 재검토에는 같은 에이전트를 사용한다. 검사자에게 대상 경로와 변경 범위, 사용자의 요청을 전달하며 맞춤법·띄어쓰기와 문장 호응뿐 아니라 뜻이 어긋나는 표현, 대사의 구어체와 상대에 맞는 말투, 선행 설명과 장면 전환도 확인하게 한다.

검사자는 원고를 직접 고치지 않는다. 작성자가 지적을 문맥과 대조해 필요한 최소 수정을 반영하고, 수정한 문단과 앞뒤를 다시 읽는다. 의미나 연결을 바꾸었거나 해결되지 않은 지적이 있으면 같은 에이전트에게 재검토를 맡긴다. 검사 에이전트 자신은 다른 에이전트를 부르지 않는다.

인물 말버릇과 허용 표기는 오류로 단정하지 않는다. 문법상 성립하지만 문맥이 어색한 표현은 규범 위반과 구별해 보고한다. 도구에서 등록된 사용자 정의 에이전트를 선택할 수 없을 때는 일반 하위 에이전트 한 명에게 에이전트 정의와 스킬을 읽게 한다. 하위 에이전트 도구가 없으면 직접 검사하고 독립 검사를 실행하지 못했음을 알린다.

최종 답변에서는 실제로 수정한 내용과 다시 읽은 범위, 독립 검사 여부만 간단히 알린다.
