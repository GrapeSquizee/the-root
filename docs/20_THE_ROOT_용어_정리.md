# THE ROOT — 용어 정리

> 2026-11-06 사용자 요청: “‘이음’처럼 한국인이 잘 안 쓰는 단어가 너무 많아 어감이 안 좋다. 한국 소설을 참고해 적절한 단어로 소설과 게임을 모두 바꿔 와.”
> 소설 1~100화와 게임 파일을 두 에이전트가 전수 조사했고, 한국 웹소설(「전지적 독자 시점」의 시스템 문구 표현)과 한국 모바일 게임의 재화·버튼 이름을 참고해 아래처럼 정했다. 새로 쓰거나 고칠 때 이 표를 따른다.

## 1. 바꾼 말

### 게임 (화면 문구와 기획 문서)

| 전 | 후 | 이유 |
|---|---|---|
| 이음 (재화·방어 자원) | **실타래** | ‘이음’만 떼면 명사로 서지 않고 숫자와 붙으면 뜻이 안 들어온다. 줄·실 소재와 이어지고 ‘실타래 120’처럼 셀 수 있다 |
| 이음 (밤에 끊긴 선을 다시 잇는 행동) | **잇기** | 재화와 행동을 나눈다 |
| 이음망 | **줄 그물** | 조어 |
| 여유 (느린 시간 자원) | **집중** | 일상어 ‘여유’와 겹친다. 게임에서 시간을 늦추는 자원은 ‘집중’이 익숙하다 |
| 흐릿한 선택 (시간 초과) | **시간 초과** | 번역투. 소설 속 화면은 ‘번진 스크린’으로 그대로 부른다 |
| 흩다 (해체자를 흩는다, 흩어라) | **쫓아내다** | 타동사 ‘흩다’는 거의 쓰지 않는다. 저절로 ‘흩어진다’는 그대로 |
| 갈래 (이야기 선택지) | **선택지** | 길이 나뉜다는 뜻의 ‘갈래’(밤의 여섯 갈래 줄)는 그대로 |
| 여기서 확정 | **여기서 멈추기** | 버튼 이름 |
| 관찰 (힌트 버튼) | **단서 보기** | 소설의 ‘관찰자’와 겹친다 |
| 멈춘 저녁 | **밤 없는 저녁** | 상태가 바로 보이게 |
| 나무가 보탠 이음 | **나무 수확** | |

코드 식별자(`ieum`, `yeoyu` 등)와 저장 데이터 키는 바꾸지 않는다. 저장이 깨지지 않게 화면 문구와 문서만 바꾼다.

### 소설

| 전 | 후 | 이유 |
|---|---|---|
| 고정자 (서린을 부르는 직함) | **매듭지기** | ‘고정자’는 전기 부품 이름과 같다. ‘문지기·등대지기’처럼 지키는 사람의 말이고 매듭 소재와 이어진다 |
| 복원자 | **복원사** | 사람을 가리킬 때 ‘-사’가 자연스럽다 |
| 매듭점 | **매듭 자리** | |
| 이름 지도 천 / 지도 천 | **이름 지도** | 명사 넷이 붙어 무겁다. 물건을 말할 때는 ‘이름 지도를 그린 천’ |
| 자루천 | **자루 천** | 띄어 쓴다 |
| 배정판 | **당번판** | |
| 기록청 | **기록소** | ‘-청’은 정부 기관 느낌. 직책 ‘기록관’은 그대로 |
| `적응 구간 종료.` / 적응 구간 | `튜토리얼 종료.` / 튜토리얼 | 웹소설 시스템 문구에서 익숙한 말 |
| `표본의 관계가 안정화되었습니다.` | `표본이 제자리를 찾았습니다.` | 번역투 |
| 출발 세계 | **원래 세계** | |
| 겹친 생명 | **두 세계의 생명** | 92화 제목도 바꾼다 |
| 중심 관계 | **중심 매듭** | ‘관계’가 사물을 가리켜 뜻이 꼬인다 |
| 명칭 (명칭 기록, 명칭 해제, 동일 명칭, 한 주소에 명칭 하나) | **이름** (이름 기록, 이름 지움, 같은 이름, 한 주소에 이름 하나) | 행정 용어 |
| 하강 중 / 하강 가속 / 하강 지속 / 하강 멈춤 | **가라앉는 중 / 빠르게 가라앉는 중 / 계속 가라앉으면 / 더 가라앉지 않음** | |
| 존속 중 | **남아 있음** | |

## 2. 그대로 두는 말

해체자(사용자가 고른 이름), 고정, 고정선, 노란 실, 붉은 줄, 파란 헝겊, 검은 매듭, 하늘색 선, 표본, 분류, 스크린, 번진 스크린, 관찰자, 판정 보류, 재관찰, 미정, 영역 안정화율, 정착지, 볕마을, 금 위, 기록 천, 기록관, 이음매, 거울토끼, 목록 밖 분, 보는 쪽·듣는 쪽·만지는 쪽, 묻는 사람·확인하는 사람·넘겨받을 사람, 하루짜리 줄, 모임터.

자연스럽거나, 작중에서 뜻을 풀어 주었거나, 인물이 일부러 쓰는 말이다.

## 3. 사용자 판단이 필요한 것

- **‘산란’이라는 이름:** 일상에서 ‘산란’은 ‘알을 낳음’이나 ‘빛의 산란’으로 먼저 읽힌다. 주요 인물 이름이라 바꾸지 않았다.
