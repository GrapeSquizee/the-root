# THE ROOT — 컨셉 재설계 (소설 기준)

> 소설 「세상을 부수고 싶다고 했더니 분류부터 시켰다」를 게임의 정사로 삼아 다시 잡은 컨셉 초안이다. 기존 [v0.3 컨셉](01_THE_ROOT_Concept_and_Gameplay_v0.3.md)과 충돌하는 부분은 이 문서가 우선한다. 확정 전 초안이며, 수치는 플레이테스트로 조정한다.

## 1. 한 줄

**낮에는 스크린의 분류 문제를 풀어 정착지의 줄을 이을 실타래를 모으고, 밤에는 그 줄을 끊으러 오는 해체자를 막아 사람들의 이름을 지키는 게임.**

## 2. 소설과 v0.3의 차이

| | v0.3 | 재설계 |
|---|---|---|
| 플레이어 | 세계 밖의 관찰자 | 연우. 세계 안에 있고 스크린은 연우만 본다 |
| 오답 | CHAOS 수치 상승 | 월드에 붉은 줄이 남고 밤에 약점이 된다 |
| 보상 | 점수, 장비 강화 | 이름 회복, 새 잎, 구역 안정화율 |
| 대가 | 점수 -50% | 서린의 손이 굳는 것, 사라지는 이름 |
| 위협 | 시간 제한 | 해체자 |
| 정답 | 개발자가 정한 Canon | Canon 유지. 단 서린의 고정(멈춤)이라는 대가가 따르는 선택지가 있다 |

## 3. 하루의 흐름

```text
아침 : 정착지 상태 확인 (새 잎, 이름, 끊긴 길)
낮   : 분류 → 실타래(방어 자원)와 붉은 줄(약점) 생성
저녁 : 방어 배치, 고정 여부 결정
밤   : 해체자 습격 (방어 페이즈)
새벽 : 결과 정산, 사라진 이름·오른 안정화율
```

## 4. 낮 — 분류

기존 카드 선택 규칙은 그대로 쓴다. 좌/우 선택, 깊이 내려가기, OBSERVE, LOCK, SKIP, 선택 타이머(`4.0`, 튜토리얼 종료 후 `2.0`)를 유지한다. 화면에는 소설처럼 단위 없이 표시하고, 구현값은 각각 약 4초와 2초로 둔다.

바뀌는 점:

- 카드는 지구의 개체(연우가 아는 지식)와 이 세계의 대상(정착지 사람, 물건, 길, 새로 배우는 지식)이 섞여 나온다.
- 정답이면 **실타래**가 쌓인다. 실타래는 밤에 쓰는 방어 자원이자 방어 구조물의 재료다.
- 오답이면 **붉은 줄**이 해당 대상에 남는다. 붉은 줄에 걸린 것은 밤에 약점이 된다. 점수가 깎이는 대신, 낮의 실수가 밤에 돌아온다. 무게는 4.2절에서 정한다.
- 빠르고 정확하게 맞힐수록 밤에 쓸 **집중(느린 시간 자원)**이 쌓인다(4.1절).
- 깊이 내려갈수록 실타래가 튼튼해진다. LOCK하면 그 깊이에서 확정되어 안전하게 방어 구조에 쓸 수 있다.

### 4.1 집중 — 낮의 속도가 밤의 시간이 된다

낮의 선택 타이머(`4.0`, 튜토리얼 종료 후 `2.0`)는 소설의 정체성이므로 유지한다. 대신 그 압박에 밤으로 이어지는 이유를 준다.

- 제한 시간 안에, 특히 남은 시간이 많을 때 정답을 고르면 **집중**이 쌓인다.
- 타이머를 넘기면 오답이 아니라 **시간 초과**로 남는다(세계 규칙 2.4절, 소설 10화의 번진 스크린). 집중은 쌓이지 않고, 실타래도 붉은 줄도 생기지 않는다. 시간 초과로 남은 자리는 해체자가 직접 끊지 못하지만, 그 주변의 이름은 흩어진다. 밤에 어떻게 다룰지는 9절에 남긴다.
- 집중은 밤에 두 곳에 쓴다.
  - 수단을 고를 때 시간이 느려지는 길이(5.0절)
  - 고정 같은 강한 수단의 재사용 간격 단축(5.4절)
- 집중은 하루 단위로 정산하며 다음 날로 넘기지 않는다. 매일 빠르게 맞히는 이유를 만든다.
- 배율과 상한은 플레이테스트에서 정한다. Vertical Slice는 밤 방어만 먼저 검증할 수 있도록 집중 없이 일정한 값으로 시작해도 된다.

### 4.2 오답의 무게 — 실수는 정보가 된다

목표: 낮에 깊이 들어가는 모험을 막지 않을 만큼 가볍게, 그러나 밤에 확실히 느껴질 만큼 무겁게. 원칙은 **낮의 실수만으로는 아무것도 잃지 않고, 잃는 것은 밤에 줄이 실제로 끊겼을 때뿐**이라는 것이다.

1. **붉은 줄은 예고된 약점이다.** 해체자는 붉은 줄 자체는 끊지 못하지만(세계 규칙 7절), 붉은 줄에 걸린 것은 약해서 먼저 끊긴다(게임에서 더한 규칙). 해체자의 경로는 저녁 단계에서 미리 보인다. 플레이어는 어디가 공격받을지 알고 대비한다. 실수가 숨은 벌칙이 아니라 밤의 작전 정보가 된다.
2. **굵기가 다르다.** 얕은 깊이에서 틀린 줄은 가늘고, 깊이 욕심을 내다 틀린 줄은 굵다. 굵은 줄에 걸린 것일수록 해체자를 더 강하게 끌어당기고 더 빨리 끊긴다. LOCK의 판단이 밤까지 이어진다.
3. **미끼로 쓸 수 있다.** 붉은 줄에 걸린 것은 해체자를 끌어당기므로(게임에서 더한 규칙), 일부러 남겨 두거나 끊기와 조합해 해체자를 한곳으로 모을 수 있다. 실수가 전략 재료가 된다.
4. **상한이 있다.** 하루 붉은 줄이 일정 수를 넘으면 그날 밤 웨이브가 하나 늘어난다. 그 이하에서는 웨이브 수가 변하지 않는다. 한 번의 실수로 밤 전체가 무너지지 않게 한다.
5. **다시 맞히면 바로잡힌다.** 붉은 줄이 남은 대상은 다음 날 다시 출제될 수 있고, 이번에 맞히면 붉은 줄이 실타래로 바뀐다. 다만 이미 잃은 이름은 돌아오지 않는다(소설 2부의 규칙). 틀린 것을 배워 고치는 흐름을 만들며, 기존 Cycle 2 재출제와 연결된다.
6. **이름 상실은 영구지만 게임 오버는 아니다.** 밤에 줄이 끊겨 이름을 잃어도 다음 날은 온다. 대신 인물의 말과 정착지 모습이 달라지고, 되찾는 길은 이야기 진행으로 연다.

## 5. 밤 — 방어

### 5.0 진행 방식 (확정)

- **실시간**으로 진행한다. 낮은 판단, 밤은 반응이라는 리듬 대비를 만든다.
- 조작은 최소화한다. 연우는 직접 움직이지 않는 **시점**이고, 플레이어는 마우스나 터치로 줄을 골라 수단을 쓴다.
- 한 판은 60~90초 안팎, 해체자 웨이브 3~4회로 한다.
- 수단을 고르는 동안에는 시간이 **느려진다**(완전 정지는 아님). 느려지는 길이는 낮에 번 집중(4.1절)으로 정해진다. 판단의 즐거움은 지키고 긴장은 유지한다.
- 해체자는 소리(사각거림)로 접근이 예고되며, 방향이 있는 소리가 방어 정보의 일부다.

### 5.1 무엇을 지키는가

- **기록 천:** 이름 있던 때의 모양이 적힌 유일한 기록이다. 해체자의 일차 목표이며, 파괴되면 해당 구역의 고정이 불가능해진다.
- **줄 그물:** 정착지 곳곳을 잇는 선이다. 끊기면 그 줄에 걸린 사람과 집이 이름을 잃는다.
- **우물:** 이름이 가라앉는 곳. 소설 기준으로 덮개를 열어 둔 채 부르면 이름이 사라진다(18화 고정 이전). 방어 대상은 아니지만 마지막 위험 지점으로 쓴다.

### 5.2 해체자

회백색 실밥을 손가락 크기로 뭉쳐 놓은 것 같은 작은 존재다. 보내는 쪽은 아직 밝히지 않는다.

게임의 목표 순서(소설 16화 기준으로 하나로 정한다):

1. 가장자리에서 나타나 줄을 따라 **기록 천**으로 향한다. 기록 천이 일차 목표다.
2. 가는 길에 줄에 걸린 것(선, 길, 이름)을 끊는다. 붉은 줄에 걸린 것을 먼저 끊는다.
3. 우물로 이어진 붉은 줄 자체는 끊지 못한다.

끊긴 선을 실타래로 다시 이으면 그 주변의 해체자가 한꺼번에 흩어진다(소설 16화). 여러 선을 연달아 끊을 수 있으므로 한 번 끊었다고 사라지지 않는다.

- 기본 해체자: 가장자리에서 천천히 접근한다.
- 후속 유형은 이후 부를 쓰면서 정한다. 이 문서에서는 이동 속도, 줄 우선도, 소리(사각거림)로 구별되는 3~4종을 가정한다.
- 해체자의 접근은 소리로 예고된다. 화면에서 보이는 범위는 좁고 소리가 중요한 정보다.

### 5.3 플레이어의 수단

| 수단 | 소설 근거 | 효과 | 비용 |
|---|---|---|---|
| 잇기 | 서린의 다시 잇기 | 끊긴 선을 복구한다. 이미 풀린 이름은 되돌아오지 않는다 | 실타래 |
| 노란 실 | 서린의 위험 표시 | 해체자 접근 경로를 예고하고 약간 늦춘다 | 실타래 |
| 파란 헝겊 | 마루의 표시 | 이름 잃은 대상을 보호 구역으로 묶는다 | 헝겊 수 한정 |
| 검은 매듭 | 마루의 매듭 | 이름을 붙잡는 방어물. 설치 지점 고정 | 이름 기억 |
| 끊기 | 연우의 선택 | 약한 선을 스스로 끊어 해체자를 한곳으로 몰아넣는다 | 그 선에 걸린 것을 포기 |
| 고정 | 서린의 방법 | 구역 전체를 이름 있던 때의 모양으로 못 박는다. 이번 밤은 안전하지만 성장이 멈춘다 | 서린의 손 굳기 게이지 |

### 5.4 고정의 딜레마

고정은 소설의 핵심 선택이므로 게임의 핵심 판단으로 만든다.

- 쓰면 그 밤은 확실히 넘긴다.
- 대신 해당 구역의 새 잎, 키, 상처처럼 자라나는 것이 멈춘다. 쌓이면 안정화율이 오르지 않는다.
- 서린의 손 굳기 게이지가 올라가고, 가득 차면 서린이 한동안 방어에 참여하지 못한다.
- 한 번 쓴 뒤 다시 쓰려면 간격이 필요하며, 낮에 번 집중으로 이 간격을 줄일 수 있다.

기존 LOCK(점수를 확정하고 더 가지 않는 선택)의 서사 버전이다.

## 6. 진행과 메타

- **안정화율:** 기존 ORDER/CHAOS를 대체한다. 이름 회복, 새 잎, 길 복구로 오른다.
- **정착지 상태:** 새 잎 수, 회복한 이름, 끊긴 길이 아침마다 보인다. 이 숫자들이 하루 단위로 변하는 것을 보여 준다.
- **인물 이벤트:** 마루, 은솔, 서린이 새벽과 아침 장면에서 반응한다. 낮 분류의 결과가 이들의 말에 반영된다.
- **장비/상점:** 기존 장비 슬롯과 상점은 폐기한다. 숯, 천, 수첩, 실 같은 기록 도구로 대체하고, 소설의 소품 설정에 맞는 소수 항목만 둔다.

## 7. 엔딩과 반전

- Overflow(ORDER 한계 초과)는 폐기하거나 소설의 평행세계 반전과 이어 재설계한다.
- 새 세계가 평행세계라는 사실은 구성안 54화 기준으로 후반 공개한다.
- Hard Mode(속성 → 개체)는 보류한다. 소설의 이어지는 전개와 맞는지 확인한 뒤 결정한다.

## 8. Godot 구현 메모

- 낮: 기존 카드 선택 씬을 재사용한다. 결과를 실타래/붉은 줄 데이터로 내보내는 부분만 새로 만든다.
- 밤: 정착지를 노드와 간선으로 표현하는 2D 그래프 맵에서 실시간으로 진행한다. 해체자는 간선을 따라 이동하고, 방어 수단은 노드 또는 간선에 설치한다. 수단 선택 중에는 `Engine.time_scale`을 낮춰 느린 시간을 만든다.
- 소리는 방어의 일부다. 방향성 오디오로 해체자 접근을 알린다.
- 낮과 밤을 잇는 공통 데이터: `줄(id, 상태, 걸린 대상, 붉은 줄 여부)`, `이름(id, 소유 대상, 상태)`.

## 9. 아직 정하지 않은 것

1. 지구 개체와 이 세계 대상의 비율, 카드 수급 방식.
2. 오답의 무게 수치: 붉은 줄 굵기 단계, 웨이브가 늘어나는 붉은 줄 상한, 재출제 빈도(구조는 4.2절에 제안).
3. 집중의 적립 규칙(남은 시간 비례 여부)과 상한, 느린 시간의 배율.
4. 고정 같은 강한 수단을 쓸 때의 예외 처리.
5. 시간 초과가 밤에 어떤 위험이 되는지. 붉은 줄과 달리 끊을 수도 이을 수도 없는 대상으로 둘 것인지.
6. 기존 장비/상점을 얼마나 남길지.
7. Vertical Slice 범위를 소설 몇 화 분량으로 정할지.

확정한 것:
- 밤은 실시간이며 연우는 조작 캐릭터가 아닌 시점이다(5.0절).
- 낮의 선택 타이머는 유지하고, 속도로 번 집중이 밤의 느린 시간으로 이어진다(4.1절).
- 낮과 밤 사이의 저녁 단계(방어 배치, 고정 결정)에는 시간 제한을 두지 않고, 밤은 60~90초로 제한하며, 새벽에는 조용한 정산 구간을 둔다. 피로를 줄이는 장치다.

| 실패해도 이야기가 앞으로 간다 | Hades | 이름을 잃은 밤에도 인물 반응과 대사가 생기고 이야기는 이어진다(4.2절 6) |
| 플레이어의 지식이 진짜 진행이다 | Outer Wilds, Return of the Obra Dinn | 붉은 줄 재출제로 틀린 분류를 배워 고친다. 스크린의 의미를 플레이어가 직접 해독한다(4.2절 5) |
| 시스템과 UI가 곧 서사다 | 「Papers, Please」, Inscryption | 스크린, 번진 스크린, 줄어드는 숫자, 붉은 줄이 설명 없이 이야기를 전한다 |
| 짧은 판과 한 판 더 | Balatro, Vampire Survivors, Slay the Spire | 하루 한 바퀴를 5~7분 안팎으로 한다. 밤은 60~90초 |
| 조합을 발견하는 재미 | Balatro, Slay the Spire | 노란 실, 끊기, 붉은 줄 미끼, 고정을 엮는 방어 조합(4.2절 3, 5.3절) |
| 지키고 싶은 인물 | Undertale, Stardew Valley | 지키는 대상이 수치가 아니라 마루, 은솔, 노인 같은 사람이다 |
| 리스크를 스스로 고른다 | Slay the Spire, Balatro | 깊이 욕심과 LOCK, 고정 사용 여부를 플레이어가 고른다(4.2절 2, 5.4절) |
| 누구나 끝까지 볼 수 있다 | Celeste(보조 모드) | 타이머 완화, 느린 시간 확대 같은 보조 옵션을 둔다 |
| 소리와 그림의 정체성 | Hollow Knight, Inscryption | 사각거리는 소리, 노란 실·붉은 줄·파란 헝겊의 색 규칙을 일관되게 쓴다 |

피할 것:

- 숙련도만을 위한 반복 플레이. 기존 Mastery 노가다를 두지 않는다는 원칙을 유지한다.
- 이유를 알 수 없는 패배. 모든 손실은 보이는 원인이 있어야 한다.
- 긴 설명문 튜토리얼. 소설 1~9화처럼 플레이 안에서 규칙을 배운다.
